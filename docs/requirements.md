# Требования и FAQ (выжимка из ТЗ)

## Данные
- Не менее 40 роликов, 10–145 с, `.mov`, от 29 FPS, без звука, ~29 МБ.
- Постановочные съёмки, ракурс сверху, одна камера, одна касса; в кадре кассир, клиенты, инкассаторы.
- Разметка: метка «нарушение» + таймкод. Тип нарушения не указан — определяем сами.
- Можно дополнять своими съёмками, синтетикой, открытыми датасетами.
- Данные использовать только в рамках хакатона; тестовые видео нельзя использовать для обучения, публиковать, передавать.

## Нарушения и вердикт
- Закрытого списка типов нет; в тесте могут быть типы, которых не было в обучении.
- Нарушения «по бездействию»: таймкод выбираем сами.
- Не утверждать нарушение, если нужны невидимые на видео данные (проводки, сверки).
- Злоупотребление неопределённым вердиктом без обоснования штрафуется.

## Проверка
- 5+ видео, загружает жюри удалённо по ссылке команды; оценка автоматическая по JSON.
- Критерий 1 считается по вердикту на всё видео.
- Нужно указать конкретный кадр и таймкод.
- Лимит 5 минут на видео, иначе «необработано».
- Питчинг только у финалистов: 5 минут + 2 минуты вопросов.

## Технологии
- Платные/закрытые API (GPT, Claude и т. п.) запрещены; дисквалификация за облачные API и готовые решения.
- GPU организатор не даёт.
- Готовый код и предобученные модели — только open source с коммерческой лицензией.
- Авторизация, история, экспорт, пакетная загрузка не нужны; язык интерфейса — на выбор.
- Звук и идентификация лиц запрещены.

## Нормативная база
- Только акты РК (НБРК, adilet.zan.kz); допустимы ссылки без точного пункта и открытые документы других банков.
- Нарушений на основе закрытых внутренних правил ForteBank в датасете нет.

## Организационное
- Дедлайн в 12:00.
- ForteBank вправе использовать решение в коммерческих целях.
